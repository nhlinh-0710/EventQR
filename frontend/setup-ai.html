🤖 Thiết Lập AI Thực Sự

Biến chatbot thành trợ lý thông minh với Google Gemini AI

1

Lấy API Key Miễn Phí

Truy cập Google AI Studio để lấy API key hoàn toàn miễn phí. Không cần thẻ tín dụng, không tốn phí!

⚡
Giới hạn miễn phí: 60 requests/phút, 1,500 requests/ngày
Đủ cho 100-300 người dùng mỗi ngày!
🔑 Lấy API Key Ngay

Các bước:

  • 1
    Đăng nhập bằng tài khoản Google (Gmail)
  • 2
    Chấp nhận điều khoản sử dụng
  • 3
    Nhấn "Create API key" → "Create API key in new project"
  • 4
    Copy API key (dạng: AIzaSy...)
2

Nhập API Key

Paste API key vừa copy vào ô bên dưới. Hệ thống sẽ tự động lưu vào file cấu hình.

🔒
Lưu ý bảo mật:
API key sẽ được lưu trong file JavaScript. Đối với production, nên dùng backend proxy để bảo mật tốt hơn.
3

Kiểm Tra & Test

Sau khi lưu API key, refresh trang và test chatbot với các câu hỏi phức tạp.

Câu hỏi test gợi ý:

✅ "Có sự kiện nào về Sơn Tùng MTP không?"
✅ "Tôi muốn tham gia sự kiện vui vui"
✅ "EventQR là gì?"
✅ "So sánh EventQR với Eventbrite"
✅ "Làm sao để tổ chức sự kiện riêng?"

🐛 Khắc Phục Lỗi

❌ Lỗi "API key not valid"

  • Kiểm tra API key đã copy đầy đủ chưa
  • Đảm bảo không có khoảng trắng thừa
  • Đợi 1-2 phút để API key được kích hoạt
  • Thử tạo API key mới

❌ Bot không trả lời

  • Mở Console (F12) xem có lỗi không
  • Kiểm tra kết nối internet
  • Refresh trang và thử lại

❌ Lỗi "Quota exceeded"

  • Đã dùng hết 60 requests/phút
  • Đợi 1 phút rồi thử lại
  • Hoặc upgrade lên paid plan
